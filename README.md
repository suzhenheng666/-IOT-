## 项目概述

**AIoT双端智能环境监控系统** 是一款深度融合嵌入式技术与云计算的企业级物联网解决方案。项目创新性地采用**STM32F4 + ESP32-S3双处理器协同架构**，通过职责分离的设计理念，实现了高性能、高可靠性的环境监控系统。

本系统不仅具备完整的数据采集、传输、存储、可视化能力，更在技术实现上展现了多项**亮眼技术**，体现了现代物联网系统的最佳实践，适用于工业4.0、智慧农业、智能仓储等多个企业级应用场景。

## 🔥 亮眼技术亮点

### 1. **双处理器协同架构（Dual Processor Collaboration）**
- **职责分离设计**：STM32F4专注底层传感器控制和本地温控决策，ESP32-S3专注网络通信、协议转换和边缘缓存
- **性能优化**：避免单一MCU既要处理实时控制又要处理复杂网络协议的性能瓶颈
- **可靠性提升**：任一处理器故障不影响另一处理器的基本功能

### 2. **实时操作系统深度应用（FreeRTOS Advanced Usage）**
- **STM32端**：基于FreeRTOS实现多任务调度，包括传感器采集任务、串口通信任务、设备控制任务
- **ESP32端**：利用ESP-IDF框架的FreeRTOS内核，实现HTTP上传任务、UART接收任务、WiFi管理任务的并发执行
- **任务间通信**：使用FreeRTOS队列（Queue）实现STM32与ESP32间的数据传递和同步

### 3. **自定义二进制通信协议（Custom Binary Protocol）**
- **高效传输**：相比JSON/XML，二进制协议减少70%以上的传输开销
- **结构体对齐控制**：使用`#pragma pack(1)`确保跨平台数据一致性
- **校验机制**：自实现校验和算法，确保数据传输完整性
- **协议扩展性**：预留命令字段和长度字段，支持未来功能扩展

### 4. **异步事件驱动服务器架构（Asynchronous Event-Driven Server）**
- **高性能后端**：基于libevent库实现异步非阻塞HTTP服务器
- **高并发处理**：单线程支持数千并发连接，内存占用极低
- **模块化路由**：自实现RESTful API路由系统，支持动态注册和分发
- **缓冲区管理**：高效的内存池和缓冲区管理，避免内存泄漏

### 5. **边缘计算与断线续传（Edge Computing & Store-and-Forward）**
- **NVS离线缓存**：网络异常时自动将传感器数据缓存到ESP32的NVS闪存，基于环形缓冲区管理，最大缓存50条
- **断线续传**：网络恢复后自动批量上传缓存数据，上传中断时保留剩余条目，下次继续补传
- **WiFi重连**：WiFi断线后自动重连，最大重试5次，基于FreeRTOS事件标志组实现状态管理
- **本地温控**：STM32端独立运行温度阈值判断，不依赖云端指令即可自动控制风扇开关

### 6. **现代化前端技术栈（Modern Frontend Stack）**
- **Vue 3 Composition API**：采用最新的Vue 3组合式API开发模式
- **ECharts数据可视化**：集成专业的数据可视化图表库
- **Axios拦截器**：实现统一的请求/响应拦截和错误处理
- **响应式设计**：适配多种终端设备的现代化UI

### 7. **企业级数据库设计（Enterprise Database Design）**
- **MySQL关系型存储**：支持复杂查询和事务处理
- **时序数据优化**：针对传感器数据的时间序列特性进行表结构优化
- **数据分层存储**：最新数据和历史数据分离存储，提升查询性能

### 8. **安全与可靠性设计（Security & Reliability）**
- **配置文件管理**：敏感信息（如数据库密码）集中管理
- **输入验证**：完整的HTTP请求参数验证和错误处理
- **日志系统**：多级别日志记录，便于问题排查和系统监控
- **资源保护**：防止缓冲区溢出、内存泄漏等常见安全问题

### 9. **云端 AI 大模型环境分析（LLM-Powered Analysis）**
- **数据驱动**：ESP32 每采集 10 条温湿度数据，批量发送至服务器
- **大模型推理**：服务端调用 DeepSeek / 通义千问 / OpenAI 等大模型分析环境趋势
- **智能建议**：返回风险等级 + 文字分析 + 可执行建议，ESP32 串口实时打印

## 系统架构详解

### 架构拓扑图
```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────────┐    ┌─────────────────┐
│   感知层        │    │   网络层        │    │   服务层            │    │   应用层        │
│  (STM32F4)      │    │  (ESP32-S3)     │    │  (C HTTP Server)   │    │  (Vue.js SPA)   │
├─────────────────┤    ├─────────────────┤    ├─────────────────────┤    ├─────────────────┤
│ • FreeRTOS RTOS │◄──►│ • FreeRTOS RTOS │◄──►│ • libevent          │◄──►│ • Vue 3         │
│ • DHT11传感器   │UART│ • UART通信      │HTTP│ • MySQL存储         │API │ • ECharts       │
│ • 本地温控判决  │    │ • NVS边缘缓存   │    │ • RESTful API       │    │ • Axios         │
│ • 自定义协议    │    │ • WiFi STA模式  │    │ • 云端 LLM AI 分析  │    │ • Vite构建      │
└─────────────────┘    └─────────────────┘    └─────────────────────┘    └─────────────────┘
```

### AI 架构 (云端大模型)
```
STM32 → ESP32 → HTTP → C Server → Python 子进程 → AI API (DeepSeek/通义/OpenAI)
  │                         │                           │
  │ 温湿度 (每2.5s)          │ 每10条数据批量            │ 环境分析 + 建议
  │                         │ POST /ai/analyze          │
  ▼                         ▼                           ▼
 传感器采集               MySQL 存储               JSON 返回 ESP32 打印
```

### 数据流说明
1. **STM32端**：DHT11传感器采集温湿度 → FreeRTOS任务调度 → 本地温度阈值判决控制风扇 → 打包自定义二进制协议 → UART发送给ESP32
2. **ESP32端**：UART接收数据 → 每条数据 HTTP 上报云端 / 每10条触发 AI 分析 → 接收 AI 分析结果 → 串口打印
3. **Server端**：libevent接收 HTTP 请求 → cJSON解析 → MySQL存储 → 调用 Python 脚本 → AI 大模型推理 → 返回分析结果
4. **Frontend端**：Axios调用RESTful API → Vue组件渲染 → ECharts可视化展示

| **边缘存储** | NVS (Non-Volatile Storage) | ESP32闪存、环形缓冲区、掉电不丢失 |
| **云端AI** | Python + LLM API | DeepSeek/通义千问/OpenAI 大模型分析 |
| **JSON处理** | cJSON | 轻量级、内存效率高 |
| **前端框架** | Vue 3 + Vite | Composition API、现代化构建 |
| **可视化** | ECharts | 专业级数据图表 |


### 配置修改
1. 修改`Server/config/server.conf`中的数据库连接信息
2. 修改`ESP32/main/main.c`中的服务器IP地址
3. 修改`Frontend/src/utils/request.js`中的API基础URL

1. 启动MySQL数据库服务
2. 运行后端服务器：`./build/MyTinyHttpd`
3. 启动前端开发服务器：`npm run dev`
4. 烧录STM32和ESP32固件
